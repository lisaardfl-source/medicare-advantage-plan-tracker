# Medicare Advantage Plan Tracker

Full-stack Medicare Advantage market and county analysis application.

## Included

- Medicare Advantage plan and county tracker frontend
- API server and shared database libraries
- CMS import and validation scripts
- Replit and pnpm workspace configuration

## Development

Install dependencies with pnpm, then use the configured Replit workflows or the package scripts.

This repository is private and contains source code only; dependencies, build output, caches, and environment files are intentionally excluded.
